# DevPulse - Autonomous Local Terminal Coding Assistant

DevPulse is a lightweight, autonomous CLI coding assistant powered by the Google Gemini API. It operates via a dual-loop ReAct (Reasoning + Acting) engine, allowing it to inspect local files, read project contexts, create folders, and write/update code directly in your workspace.

---

## ⚡ Features

- **Dual-Loop ReAct Engine**: Maintains an interactive terminal chat loop while dynamically resolving chained tool executions in real-time.
- **Autonomous File Management**:
  - `look_inside_folder`: Explores workspace structure and directory contents.
  - `read_file`: Reads text and source files directly to inspect implementations.
  - `create_folder`: Creates nested directory structures safely.
  - `write_file`: Generates or updates code and configuration files.
- **Gemini Function Calling**: Built on the official `google-genai` SDK using structured tool declarations.

## 🛠️ Prerequisites

- Python 3.9+
- A Google Gemini API key ([Get an API Key](https://aistudio.google.com/))

---

## 🚀 Setup & Installation

1. **Clone or download this repository** into your desired workspace directory.

2. **Install Required Dependencies**:
   ```bash
   pip install google-genai python-dotenv
   ```

3. **Configure Environment Variables**:
   Create a `.env` file in the project root directory and add your Gemini API key:
   ```env
   GEMINI_API_KEY=your_gemini_api_key_here
   ```

---

## 💻 Usage

Launch DevPulse from your terminal:

```bash
python main.py
```

Once running, you can interactively give instructions such as:
- *"Explore the repository and create a README file."*
- *"Refactor main file to handle errors better."*
- *"Create a new modular project structure under `src/`."*

Type `exit` or `quit` to end the session.

## 📂 Architecture Overview

```
User Input ──► Outer Interactive Loop (Chat Session)
                    │
                    ▼
         Gemini API (Reasoning)
                    │
           Function Call Request
                    │
                    ▼
         Inner Tool Resolution Loop
   ┌────────────────────────────────┐
   │ • look_inside_folder()          │
   │ • read_file()                  │
   │ • create_folder()              │
   │ • write_file()                 │
   └────────────────────────────────┘
                    │
                    ▼
       Tool Execution Result Sent Back
```
